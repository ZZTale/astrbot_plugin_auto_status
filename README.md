# QQ 状态自动管理插件 (AstrBot)

为 AstrBot 打造的 QQ 状态管理插件。支持开机自动设置在线状态、AI聊天切换状态、一键修改状态指令。

## ⚠️ 用前声明
- 本插件基本使用 AI 编写，已在当前使用的 AstrBot 版本下实测可用。
- 本插件仅适配 **aiocqhttp（NapCat）**，在其他协议端可能无法工作。

## ✨ 功能一览
- **智能切换**：可以通过自然语言让 AI 自行改变状态（如：“去睡觉吧”）。
- **启动时设置在线状态**：机器人连接成功后，自动设置为在线状态。
- **一键强制指令**：使用 `/force <状态名>` 强制所有选中机器人切换对应状态。

## 🛠️ 安装方法
- 将本仓库放入 AstrBot 的 `data/plugins/` 目录下。
- 仓库地址：https://github.com/ZZTale/astrbot_plugin_auto_status
- 或直接在 AstrBot 的插件市场搜索astrbot_plugin_auto_status，点击安装，等待完成即可。

## 🚀 指令示例
- `/force 在线`：强制所有白名单机器人上线。
- `/force 摸鱼中`：强制所有白名单机器人切换到摸鱼状态。

## 💡 配置说明
- **允许修改状态的QQ号白名单**：只有在这里的 QQ 才能让 AI 切换状态以及使用一键修改指令。
- **自定义状态映射表**：支持 `状态名,基础码,扩展码` 或 `状态名,基础码,自定义文字,图标ID`。具体状态码不一一列出，默认配置中自带部分状态码。
- **具体配置示例参见插件默认配置**
